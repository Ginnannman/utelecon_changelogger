## 日本語

```diff
  課題，テスト，アンケートは，いずれも担当教員が作成するもので（授業アンケートを除く），コーストップの各欄に表示されます．それぞれのタイトルを押すと提出・回答画面に移り，提出あるいは回答することができます．
  また，右側の![︙](/_astro/control_btn_icon.webp)を押すと，テストの結果やアンケートの集計結果などを見られます．ただし，一部の項目は担当教員が表示・非表示を設定するため，表示されない場合があります．
+ 2026年9月29日より，担当教員が「課題」ごとにAI利用範囲を設定するようになります．設定された課題では，提出画面にその範囲が表示されますので，課題に取り組む前に確認してください．詳しくは「[UTOLの課題機能でAI利用範囲の設定が必須になります](/notice/2026/0928-utol-ai/)」をご覧ください．
  課題の「提出する」ボタンを押しても，ネットワークの不調などが原因で提出処理が正しく行えず未提出となることがありますので，提出時には以下のことを確認してください．
  - 課題成果物の提出後に「提出が完了しました」というメッセージが表示されたことを必ず確認してください．
```

## English

```diff
  Assignments, quizzes, and surveys are all created by your course instructor (except for class surveys) and are displayed in the respective columns on the Course Top screen. Clicking the respective title will take you to the submission • response screen, where you can submit or answer it.
  If you press ![︙](/_astro/control_btn_icon.webp) on the right-hand side, you can view the results of the quizzes or surveys. Please note that some items may not be displayed as they are set to be displayed or hidden by your course instructor.
+ From September 29, 2026, course instructors will set the Permitted AI Use for each “Assignment”. For assignments with this setting, the permitted use is shown on the submission screen, so please check it before working on the assignment. For more details, please see “[Setting “Permitted AI Use” Will Become Required in UTOL Assignments](/en/notice/2026/0928-utol-ai/)”.
  Even if you press the “Submit” button for an assignment, there may be cases where the submission process is not completed correctly due to various reasons, such as network issues, resulting in the assignment not being submitted. Please check the following when submitting:
  - After submitting the assignment, make sure that the message “Submit is completed” is displayed.
```
