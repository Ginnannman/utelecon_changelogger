## 日本語

```diff
  説明: 本サイトは，東京大学で利用可能な情報システムに関する情報をワンストップで得られることを目指すサイトです．
  
- 現在，[UTokyo Wi-Fiアカウントメニュー](/utokyo_wifi/#apply)へのアクセスを学内ネットワーク経由に限定しています．これはシステムへの攻撃を予防するための臨時の措置です．復旧の見通しは別途お伝えします．UTokyo Wi-Fiのアカウント発行申請に利用できるネットワーク接続が得られない場合は，[UTokyo VPN](/utokyo_vpn/)や[ECCS環境](/eccs/)などの利用もご検討ください．[2026年10月22日11時30分]
- Access to the [UTokyo Wi-Fi Account Menu](/en/utokyo_wifi/#apply) is currently restricted to connections via the on-campus network. This is a temporary measure to prevent attacks on the system. Information regarding restoration will be provided separately. If you do not have a network connection available to apply for a UTokyo Wi-Fi account, please consider using [UTokyo VPN](/en/utokyo_vpn/) or the [ECCS environment](/en/eccs/). [October 22, 2026, 11:30 AM]
  ## 新しく東京大学の一員となった方へ
  [学生の方](/oc/)
```
